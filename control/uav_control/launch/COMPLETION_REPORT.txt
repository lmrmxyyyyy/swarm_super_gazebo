🔧 关键参数说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

uav_name (所有launch文件都支持):
  - 默认值: uav1
  - 用途: 无人机标识，创建命名空间
  - 传递方式: uav_name:=uav2

start_x, start_y, start_z (jy_real.launch):
  - 默认值: 0.0, 0.0, 1.0
  - 用途: 规划器初始化位置
  - 示例: start_x:=1.0 start_y:=0.0 start_z:=1.0

auto_offboard (control_real_jy2025.launch):
  - 默认值: true
  - 用途: 是否自动进入Offboard模式
  - 传递方式: auto_offboard:=false

rviz (mapping_mid360.launch):
  - 默认值: true
  - 用途: 是否启动RVIZ可视化
  - 传递方式: rviz:=false

硬件要求:
  - CPU: 8核+ (每架无人机需要2核)
  - 内存: 16GB+ (每架无人机需要500-800MB)
  - 网络: UDP延迟 < 50ms

配置检查清单:
  ☐ MAVROS系统ID不重复 (UAV1=1, UAV2=2)
  ☐ UDP通信端口配置正确
  ☐ LIDAR硬件接口不冲突
  ☐ 规划起点设置合理
  ☐ 足够的CPU和内存资源

常见错误排查:
  ✗ 节点名称冲突
    → 确保启动命令中包含 uav_name:=uav1 或 uav_name:=uav2
  
  ✗ 无法收到Odometry
    → 运行 rostopic list 检查 /uav1/Odometry 是否存在
  
  ✗ MAVROS无法连接
    → 检查UDP端口配置，确保PX4模拟器运行
  
  ✗ 规划器无输出
    → 调整 start_x, start_y, start_z 参数
